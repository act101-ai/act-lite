# Security policy

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting: on
this repository's **Security** tab, select **Report a vulnerability**, or open
<https://github.com/act101-ai/act-lite/security/advisories/new>.

Do not open a public issue for a vulnerability.

## Scope

The `act-lite` binary, its MCP server, `act-lite env`, and the Claude Code
plugin in `plugin/`.

## Supported versions

The latest release.
